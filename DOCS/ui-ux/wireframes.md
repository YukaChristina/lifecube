# ワイヤーフレーム

この文書では、スマホ向けの初期ワイヤーフレームを管理します。

現時点では、詳細なビジュアルデザインではなく、画面内の優先順位と導線を確認するためのものです。

## 起動直後 / カメラ

```text
+--------------------------------+
|                                |
|                                |
|        camera preview          |
|                                |
|                                |
|                                |
|                                |
|         listening              |
|                                |
|                                |
|                                |
|                                |
|             ( ○ )              |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 起動直後からカメラを表示する。
- 画面の主役は常にカメラプレビュー。
- 音声認識状態は控えめに表示する。
- シャッターボタンは残す。
- 下部タブは撮影体験を邪魔しない高さにする。
- タブ表記は日本語にする。

## 初回権限許可

```text
+--------------------------------+
|                                |
|      camera-like backdrop      |
|                                |
|      +------------------+      |
|      | カメラとマイクを使います |      |
|      | 撮影のために許可してください |      |
|      +------------------+      |
|                                |
|             allow              |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- OS標準の権限ダイアログ自体は自由にデザインできない。
- アプリ側では、ダイアログを出す前の短い事前説明を設計できる。
- 事前説明を出す場合も、写真やカメラ体験を重くしすぎない。
- 権限未許可時もカメラ画面風の背景として扱う。
- 拒否された場合は、次回以降も再許可または設定変更の導線を出す。

## 権限拒否後

```text
+--------------------------------+
|      camera-like backdrop      |
|                                |
|      +------------------+      |
|      | 撮影には許可が必要です   |      |
|      | 設定から許可できます     |      |
|      +------------------+      |
|                                |
|          許可を確認する          |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 一度拒否した後も、ユーザーが再試行できる導線を残す。
- OSダイアログを再表示できない場合は、設定アプリへの導線にする。
- 表現は強い警告にせず、カメラを使うための案内として扱う。

## 前後撮影中

```text
+--------------------------------+
|                                |
|        front camera            |
|        switching view          |
|                                |
|                                |
|     /--------------------\     |
|    | 撮影切り替え中です       |    |
|    | カメラを動かさないでください |    |
|     \--------------------/     |
|                                |
|                                |
|                                |
|             ( ○ )              |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 外側撮影後、内側カメラに切り替わる。
- 約 0.5 秒のラグがあるため、動かさないよう促す。
- メッセージは短く、写真プレビューを過度に隠さない。
- 枠線やメッセージの色は、Quiet Pastel / Soft Editorial の方向で調整する。
- 背景は半透明にし、カメラ映像を完全に隠さない。

## 撮影後プレビュー

```text
+--------------------------------+
|                                |
|        composed preview        |
|                                |
|     smooth diagonal cut        |
|                                |
|                                |
|                                |
|                                |
|          保存しました             |
|                                |
|      Instagramで共有             |
|      タップでカメラへ             |
|                                |
+--------------------------------+
```

要点:

- 撮影後は合成後写真を表示する。
- デフォルトはゆるやかな斜めカット。
- 4秒経過、またはタップでカメラに戻る。
- 外側写真、内側写真、合成後写真を自動保存する。
- 保存完了表示を出す。
- SNS共有導線を出す。
- 保存ボタン、撮り直しボタンは出さない。

## アルバム一覧

```text
+--------------------------------+
| アルバム                         |
|                                |
|  2026.05.06                    |
|  +-----+ +-----+ +-----+ +----+ |
|  | set | | set | | set | |set | |
|  +-----+ +-----+ +-----+ +----+ |
|                                |
|  2026.05.05                    |
|  +-----+ +-----+ +-----+ +----+ |
|  | set | | set | | set | |set | |
|  +-----+ +-----+ +-----+ +----+ |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 日付ごとに写真セットを並べる。
- 一覧に出すのは合成後写真のみ。
- 列数はスマホで4列程度を基本にする。
- 時刻表示は必須ではない。
- 元の外側写真、内側写真は一覧に直接並べない。
- 合成後写真が削除されている写真セットは表示しない。
- 合成後写真が残っていれば、元写真が欠けていても一覧には表示する。

## アルバム詳細 / 合成パターン選択

```text
+--------------------------------+
|  <                              |
|                                |
|        composed preview        |
|                                |
|              1 / 3             |
|                                |
|                                |
|   < swipe horizontally >       |
|                                |
|        [ オリジナルを見る ]        |
|                                |
|                 Instagram      |
|                                |
+--------------------------------+
```

要点:

- 詳細の主表示は合成後写真。
- 左右スワイプだけで 3 パターンを切り替える。
- 選択したパターンは保存する。
- 「オリジナルを見る」は写真に少し重なる半透明ボタンにする。
- Instagram 共有導線を置き、共有対象は合成後写真だけにする。
- 合成パターン名は表示しない。

```text
|  +--------------------------+  |
|  |                          |  |
|  +--------------------------+  |
|                                |
|  内側                           |
|  +--------------------------+  |
|  |                          |  |
|  +--------------------------+  |
|                                |
+--------------------------------+
```

要点:

- 元写真は詳細画面の補助ビューとして扱う。
- 合成後写真と元写真をアルバム一覧で同列に並べない。
- 外側写真を上、内側写真を下に並べる。

## ホーム

```text
+--------------------------------+
| ホーム                          |
|                                |
| アプリ説明                       |
|  LifeCube の短い説明             |
|                                |
| 合成パターン設定                  |
|  +-----+ +-----+ +-----+        |
|  |     | |     | |     |        |
|  +-----+ +-----+ +-----+        |
|                                |
| 課金設定                         |
|  準備中                          |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- ホームにはアプリ説明、合成パターン設定、課金設定入口を置く。
- 合成パターン設定はサンプル画像をタップして選ぶ。
- パターン名は表示せず、見た目で選ばせる。
- 課金設定はMVPでは「準備中」と表示する。
