# ワイヤーフレーム

この文書では、スマホ向けの初期ワイヤーフレームを管理します。

現時点では、詳細なビジュアルデザインではなく、画面内の優先順位と導線を確認するためのものです。

## 起動直後 / カメラ

```text
+--------------------------------+
|                                |
|                                |
|        camera preview          |
|                                |
|                                |
|                                |
|                                |
|         listening              |
|                                |
|                                |
|                                |
|                                |
|             ( ○ )              |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 起動直後からカメラを表示する。
- 権限状態やカメラ起動状態を読み込んでいる短い間は、権限案内を出さず静かなカメラ風背景だけを表示する。
- 画面の主役は常にカメラプレビュー。
- 音声認識状態は控えめに表示する。
- シャッターボタンは残す。
- 下部タブは撮影体験を邪魔しない高さにする。
- タブ表記は日本語にする。

## 初回権限許可

```text
+--------------------------------+
|                                |
|      camera-like backdrop      |
|                                |
|      +------------------+      |
|      | カメラとマイクを使います |      |
|      | 撮影のために許可してください |      |
|      +------------------+      |
|                                |
|             allow              |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- OS標準の権限ダイアログ自体は自由にデザインできない。
- アプリ側では、ダイアログを出す前の短い事前説明を設計できる。
- 事前説明を出す場合も、写真やカメラ体験を重くしすぎない。
- 権限未許可時もカメラ画面風の背景として扱う。
- 拒否された場合は、次回以降も再許可または設定変更の導線を出す。

## 権限拒否後

```text
+--------------------------------+
|      camera-like backdrop      |
|                                |
|      +------------------+      |
|      | 撮影には許可が必要です   |      |
|      | 設定から許可できます     |      |
|      +------------------+      |
|                                |
|          許可を確認する          |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 一度拒否した後も、ユーザーが再試行できる導線を残す。
- OSダイアログを再表示できない場合は、設定アプリへの導線にする。
- 表現は強い警告にせず、カメラを使うための案内として扱う。

## 前後撮影中

```text
+--------------------------------+
|                                |
|        front camera            |
|        switching view          |
|                                |
|                                |
|     /--------------------\     |
|    | 撮影切り替え中です       |    |
|    | カメラを動かさないでください |    |
|     \--------------------/     |
|                                |
|                                |
|                                |
|             ( ○ )              |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 外側撮影後、内側カメラに切り替わる。
- 約 0.5 秒のラグがあるため、動かさないよう促す。
- メッセージは短く、写真プレビューを過度に隠さない。
- 枠線やメッセージの色は、Quiet Pastel / Soft Editorial の方向で調整する。
- 背景は半透明にし、カメラ映像を完全に隠さない。

## 撮影後プレビュー

```text
+--------------------------------+
|  画面をタップでカメラへ戻る       |
|--------------------------------|
|                                |
|        composed preview        |
|                                |
|     smooth diagonal cut        |
|                                |
|                                |
|      background tap area       |
|                                |
|                                |
|               [Instagramで共有] |
|                                |
|                         [削除する] |
|                                |
+--------------------------------+
```

要点:

- 撮影後は合成後写真を表示する。
- デフォルトはゆるやかな斜めカット。
- 4秒経過、または背景部分のタップでカメラに戻る。
- 上部に「画面をタップでカメラへ戻る」を表示する。
- 上部案内はボタンに見せず、薄い帯と下線で画面全体にかかる案内として見せる。
- アプリ内には外側写真、内側写真、合成後写真の3枚を自動保存する。
- 端末の写真アプリには合成後写真だけを自動保存する。
- 写真セット情報はSQLiteに保存する。
- 保存完了表示は出さない。
- 「Instagramで共有」は1行のボタンとして出す。
- 「削除する」ボタンを出す。
- 共有と削除のボタンは、誤タップを避けるために十分に離す。
- 共有ボタンはOS共有シートを開く。
- 削除ボタンは確認なしで即時にカメラへ戻る。
- 背景タップ領域とボタン領域は分ける。
- 保存ボタン、撮り直しボタンは出さない。

## アルバム一覧

```text
+--------------------------------+
| アルバム                         |
|                                |
|  2026.05.06 Wed                |
|  +------+ +------+ +------+    |
|  | set  | | set  | | set  |    |
|  |      | |      | |      |    |
|  +------+ +------+ +------+    |
|                                |
|  2026.05.05 Tue                |
|  +------+ +------+ +------+    |
|  | set  | | set  | | set  |    |
|  |      | |      | |      |    |
|  +------+ +------+ +------+    |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- 日付ごとに写真セットを並べる。
- 日付見出しは `2026.05.06 Wed` のように表示する。
- 一覧に出すのは合成後写真のみ。
- 列数はスマホで3列程度を基本にする。
- サムネイルは9:16の縦長表示を基本にする。
- 時刻表示は必須ではない。
- 元の外側写真、内側写真は一覧に直接並べない。
- 合成後写真が削除されている写真セットは表示しない。
- 合成後写真が残っていれば、元写真が欠けていても一覧には表示する。

## アルバム詳細

```text
+--------------------------------+
|  <                              |
|                                |
|        composed preview        |
|                                |
|          contain display       |
|                                |
|                                |
|                                |
|        [ オリジナルを見る ]        |
|                                |
|               [Instagramで共有] |
|                         [削除する] |
|                                |
+--------------------------------+
```

要点:

- 詳細の主表示は合成後写真。
- MVP初期では保存済みの1パターンだけを表示する。
- 合成後写真は `contain` 表示にし、写真全体を見せる。
- 左右スワイプでの3パターン切り替えと選択保存は、合成パターン3種類の実装時に追加する。
- 「オリジナルを見る」は写真に少し重なる半透明ボタンにする。
- Instagram 共有導線を置き、共有対象は合成後写真だけにする。
- 合成パターン名は表示しない。
- 「削除する」導線を置く。
- 詳細画面の削除は確認ダイアログを出す。
- 削除確定後はアルバム一覧へ戻る。
- アプリ内保存の写真セットは削除するが、端末写真アプリ側の合成後写真はMVP初期では削除しない。

## ホーム

```text
+--------------------------------+
| ホーム                          |
|                                |
| アプリ説明                       |
|  LifeCube の短い説明             |
|                                |
| 合成パターン設定                  |
|  +-----+ +-----+ +-----+        |
|  |     | |     | |     |        |
|  +-----+ +-----+ +-----+        |
|                                |
| 課金設定                         |
|  準備中                          |
|                                |
+--------------------------------+
|   カメラ    アルバム    ホーム   |
+--------------------------------+
```

要点:

- ホームにはアプリ説明、合成パターン設定、課金設定入口を置く。
- MVP初期の合成パターン設定は、斜めカットだけを選択中として表示する。
- 円形くりぬきと左右分割はサンプル枠だけ表示し、グレーアウトして選択不可にする。
- 合成パターン3種類の実装後は、サンプル画像をタップして選べるようにする。
- パターン名は表示せず、見た目で選ばせる。
- 課金設定はMVPでは「準備中」と表示する。
