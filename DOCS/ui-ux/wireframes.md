# ワイヤーフレーム

この文書では、スマホ向けの初期ワイヤーフレームを管理します。

現時点では、詳細なビジュアルデザインではなく、画面内の優先順位と導線を確認するためのものです。

## 起動直後 / カメラ

```text
+--------------------------------+
|                                |
|                                |
|        camera preview          |
|                                |
|                                |
|                                |
|                                |
|      「シャッター」で撮影       |
|                                |
|                                |
|                                |
|                                |
|             ( ○ )              |
|                                |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- 起動直後からカメラを表示する。
- 権限状態やカメラ起動状態を読み込んでいる短い間は、権限案内を出さず静かなカメラ風背景だけを表示する。
- 画面の主役は常にカメラプレビュー。
- 音声案内は控えめに表示する。小さなドットだけの表示は意味が伝わりにくいため使わない。
- 案内文は `「シャッター」と言うと撮影します` を仮とし、将来的な音声トリガー追加に合わせて見直す。
- シャッターボタンは残す。
- 下部タブは撮影体験を邪魔しない高さにする。
- タブ表記は日本語にする。

## 初回権限許可

```text
+--------------------------------+
|                                |
|      camera-like backdrop      |
|                                |
|      +------------------+      |
|      | カメラとマイクを使います |      |
|      | 撮影のために許可してください |      |
|      +------------------+      |
|                                |
|             allow              |
|                                |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- OS標準の権限ダイアログ自体は自由にデザインできない。
- アプリ側では、ダイアログを出す前の短い事前説明を設計できる。
- 事前説明を出す場合も、写真やカメラ体験を重くしすぎない。
- 権限未許可時もカメラ画面風の背景として扱う。
- 拒否された場合は、次回以降も再許可または設定変更の導線を出す。

## 権限拒否後

```text
+--------------------------------+
|      camera-like backdrop      |
|                                |
|      +------------------+      |
|      | 撮影には許可が必要です   |      |
|      | 設定から許可できます     |      |
|      +------------------+      |
|                                |
|          許可を確認する          |
|                                |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- 一度拒否した後も、ユーザーが再試行できる導線を残す。
- OSダイアログを再表示できない場合は、設定アプリへの導線にする。
- 表現は強い警告にせず、カメラを使うための案内として扱う。

## 前後撮影中

```text
+--------------------------------+
|                                |
|        front camera            |
|        switching view          |
|                                |
|                                |
|     /--------------------\     |
|    | 撮影切り替え中です       |    |
|    | カメラを動かさないでください |    |
|     \--------------------/     |
|                                |
|                                |
|                                |
|             ( ○ )              |
|                                |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- 外側撮影後、内側カメラに切り替わる。
- カメラ切り替えにラグがあるため、動かさないよう促す。
- メッセージは短く、写真プレビューを過度に隠さない。
- 枠線やメッセージの色は、Quiet Pastel / Soft Editorial の方向で調整する。
- 背景は半透明にし、カメラ映像を完全に隠さない。

## 撮影後プレビュー

```text
+--------------------------------+
|  画面をタップでカメラへ戻る       |
|--------------------------------|
|                                |
|        composed preview        |
|                                |
|       circle inset preview     |
|                                |
|                                |
|      background tap area       |
|                                |
|                                |
|               [Instagramで共有] |
|                                |
|                         [削除する] |
|                                |
+--------------------------------+
```

要点:

- 撮影後は合成後写真を表示する。
- デフォルトは円形くりぬき。
- 4秒経過、または背景部分のタップでカメラに戻る。
- 4秒の進捗は高さ8pxの控えめなバーで表示し、左から右へ進む。
- 上部に「画面をタップでカメラへ戻る」を表示する。
- 上部案内はボタンに見せず、薄い帯と下線で画面全体にかかる案内として見せる。
- 前後カメラ撮影では、アプリ内に外側写真、内側写真、合成後写真の3枚を自動保存する。
- 背面カメラのみ撮影では、背面写真1枚を LifeCube アルバムと端末の写真アプリに保存する。
- 端末の写真アプリには成果物画像だけを自動保存する。
- 写真セット情報はSQLiteに保存する。
- 保存完了表示は出さない。
- 「Instagramで共有」は1行のボタンとして出す。
- 「削除する」ボタンを出す。
- 共有と削除のボタンは、誤タップを避けるために十分に離す。
- 共有ボタンはOS共有シートを開く。
- 削除ボタンは確認なしで即時にカメラへ戻る。
- 背景タップ領域とボタン領域は分ける。
- 保存ボタン、撮り直しボタンは出さない。

## アルバム一覧

```text
+--------------------------------+
| アルバム                         |
|                                |
|  2026.05.06 Wed                |
|  +------+ +------+ +------+    |
|  | set  | | set  | | set  |    |
|  |      | |      | |      |    |
|  +------+ +------+ +------+    |
|                                |
|  2026.05.05 Tue                |
|  +------+ +------+ +------+    |
|  | set  | | set  | | set  |    |
|  |      | |      | |      |    |
|  +------+ +------+ +------+    |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- 日付ごとに写真セットを並べる。
- 日付見出しは `2026.05.06 Wed` のように表示する。
- 一覧に出すのは合成後写真のみ。
- 一覧は4列ベースの Mosaic / Quilted grid とする。
- 縦長写真は `1列 x 2行`、横長写真は `2列 x 1行`、必要に応じて小さく見せる写真は `1列 x 1行` とする。
- サムネイルは一覧では `cover` 表示にする。
- 時刻表示は必須ではない。
- 元の外側写真、内側写真は一覧に直接並べない。
- 合成後写真が削除されている写真セットは表示しない。
- 合成後写真が残っていれば、元写真が欠けていても一覧には表示する。

## アルバム詳細

```text
+--------------------------------+
|  <                              |
|                                |
|        composed preview        |
|                                |
|          contain display       |
|                                |
|                                |
|                                |
|        [ オリジナルを見る ]        |
|                                |
|               [Instagramで共有] |
|                         [削除する] |
|                                |
+--------------------------------+
```

要点:

- 詳細の主表示は合成後写真。
- MVP初期では保存済みの1パターンだけを表示する。
- 合成後写真は `contain` 表示にし、写真全体を見せる。
- 左右スワイプでの3パターン切り替えと選択保存は、合成パターン3種類の実装時に追加する。
- 「オリジナルを見る」は写真に少し重なる半透明ボタンにする。
- Instagram 共有導線を置き、共有対象は成果物画像だけにする。
- 合成パターン名は表示しない。
- 「削除する」導線を置く。
- 詳細画面の削除は確認ダイアログを出す。
- 削除確定後はアルバム一覧へ戻る。
- アプリ内保存の写真セットは削除するが、端末写真アプリ側の合成後写真はMVP初期では削除しない。

## ガイド

```text
+--------------------------------+
| ガイド                          |
|                                |
| 撮影方法                         |
|  「シャッター」と言うと撮影します |
|                                |
| 撮影の流れ                       |
|  1. 外側を撮影                   |
|  2. 内側を撮影                   |
|  3. 合成プレビューを表示          |
|                                |
| アルバム                         |
|  撮影した写真はアルバムで確認     |
|                                |
| 保存と削除                       |
|  端末の写真アプリにも保存されます |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- ガイドは撮影方法を確認するための補助画面にする。
- 初期実装では簡素なたたき台を置く。
- 内容は後から整理する。
- LifeCube内アルバムと端末の写真アプリの保存先が分かれていることを軽く説明する。
- 初回起動時に強制表示するチュートリアルにはしない。

## ホーム

```text
+--------------------------------+
| ホーム                          |
|                                |
| アプリ説明                       |
|  LifeCube の短い説明             |
|                                |
| 合成パターン設定                  |
|  +-----+ +-----+ +-----+        |
|  |     | |     | |     |        |
|  +-----+ +-----+ +-----+        |
|                                |
| 課金設定                         |
|  準備中                          |
|                                |
+--------------------------------+
| カメラ  アルバム  ガイド  ホーム |
+--------------------------------+
```

要点:

- ホームにはアプリ説明、合成パターン設定、課金設定入口を置く。
- アルバムとホームは、共通の見出し余白、見出しサイズ、Quiet Pastel の背景トーンで揃える。
- 合成パターン設定は、3種類のサンプル画像をタップして選べるようにする。
- 斜めカットのサンプルは、右上から左下へ抜ける3次ベジェ曲線の分割として見せ、上側を外側写真、下側を内側写真として扱う。
- 初期値は円形くりぬきにする。
- パターン名は表示せず、見た目で選ばせる。
- 課金設定はMVPでは「準備中」と表示する。
