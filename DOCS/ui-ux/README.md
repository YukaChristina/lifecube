# UI/UX ドキュメント

このフォルダでは、LifeCube の UI/UX 方針、画面構成、保存体験、MVP範囲を管理します。

現時点では、スマホ向けのカメラ体験とアルバム体験を最優先で設計します。スマホの横向き撮影は直近対応に含め、iPad のような大きめ端末の最適化は将来対応として検討します。

## 現在の設計姿勢

- アプリ起動直後はカメラ画面を表示する。
- 権限状態やカメラ起動状態の読み込み中は、権限案内を出さず静かなカメラ風背景だけを表示する。
- MVP の中核は、音声検知による前後カメラ撮影と、前後写真セットを扱うアルバム。
- 下部タブはカメラ、アルバム、ガイド、ホームで構成する。
- ガイドは撮影方法を確認する補助画面として使う。
- ホームは説明、設定、課金設定の入口として使う。
- `index` ルートをカメラ画面にし、アルバムは写真セットDBの一覧、ガイドは撮影方法、ホームは説明・合成パターン設定・課金設定入口へ接続する。
- 撮影後プレビューは、上部の薄い案内帯、背景タップでカメラ復帰、4秒進捗バー、`Instagramで共有`、`削除する` の導線を基本形にする。
- 保存基盤は `expo-sqlite` のローカルDBとアプリ内ファイル保存を使う。前後カメラ撮影ではアプリ内に3枚、背面カメラのみ撮影では背面写真1枚を保存する。端末の写真アプリには成果物画像だけを保存する。
- PC 利用は正式な想定対象にしない。
- iOS / Android の両方を対象にする。
- ネイティブ機能は、まず Expo modules と React Native ライブラリから利用する。
