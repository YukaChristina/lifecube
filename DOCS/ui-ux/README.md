# UI/UX ドキュメント

このフォルダでは、LifeCube の UI/UX 方針、画面構成、保存体験、MVP範囲を管理します。

現時点では、スマホ向けのカメラ体験とアルバム体験を最優先で設計します。iPad や横向き端末の最適化は重要ですが、MVP の初期設計ではスマホ画面を先に固めます。

## 読む順番

1. `mvp-ui-ux.md`
2. `storage-and-platform-feasibility.md`
3. `wireframes.md`
4. `design-guidelines.md`

## 現在の設計姿勢

- アプリ起動直後はカメラ画面を表示する。
- MVP の中核は、音声検知による前後カメラ撮影と、前後写真セットを扱うアルバム。
- 下部タブはカメラ、アルバム、ホームで構成する。
- ホームは説明、設定、課金設定の入口として使う。
- PC 利用は正式な想定対象にしない。
- iOS / Android の両方を対象にする。
- ネイティブ機能は、まず Expo modules と React Native ライブラリから利用する。
