# 顔検出による内側写真フォーカス補正

この文書は、前後カメラ撮影後に内側写真の顔位置を検出し、合成時に顔が見えやすい位置へ寄せる方針を整理します。

ここで扱うのは顔認識ではなく顔検出です。人物の本人確認はしません。内側写真の中で顔が写っている位置を見つけ、`frontImageFocusX`、`frontImageFocusY`、`frontImageScale` に反映します。

## 目的

- 家族の反応や撮影者側の表情を、合成写真の中で見えやすく残す。
- 顔が端に寄った内側写真でも、可能な範囲で顔を合成領域の中心へ近づける。
- 過剰なズームや不自然な空白補完より、自然な写真として残ることを優先する。

## 採用方針

- 新規撮影時の内側写真にだけ顔検出を適用する。
- 既存写真には自動適用しない。
- 既存写真の再合成時も、当面は検出し直さない。
- 顔検出に失敗した場合は、ユーザー通知を出さず `0.5 / 0.5 / 1.0` にフォールバックする。
- 複数人が写っている場合は、一番大きい顔を優先する。
- `円形 / 斜め / 分割` のすべてで同じ `frontImageFocus` を使う。
- 合成時の見え方は、パターンごとの表示領域に合わせて描画側で調整する。

複数人全員を最適に収めるには、顔群の外接矩形、表示領域、拡大率、斜めカット領域との重なりを同時に調整する必要があります。MVP では複雑にしすぎないため、一番大きい顔を優先します。

## 技術候補

第一候補は `@infinitered/react-native-mlkit-face-detection` です。

- Expo Module として提供されており、Expo / React Native 構成と相性がよい。
- Google ML Kit の端末内顔検出を React Native から利用する。
- バックエンドサーバーや Google ログインは不要。
- native module 追加になるため、development build の作り直しが必要。

代替候補:

- `@react-native-ml-kit/face-detection`
- ML Kit を直接呼ぶ小さな Expo native module
- 将来リアルタイム検出が必要になった場合の `react-native-vision-camera` + frame processor

MVP ではリアルタイム検出は不要です。撮影後の内側写真1枚に対して検出できれば足ります。

## 処理フロー

```text
+-----------------+       +-----------------+
|  back.jpg       |       |  front.jpg      |
|  外側写真        |       |  内側写真        |
|                 |       |   +-------+     |
|                 |       |   |  顔   |     |
|                 |       |   +-------+     |
+-----------------+       +-----------------+
                              |
                              v
                       ML Kit 顔検出
                              |
                              v
                    最大の顔の bounds を選ぶ
                              |
                              v
             frontImageFocusX / Y / Scale を計算
                              |
                              v
       composePhotos(front, back, pattern, orientation, focus)
                              |
                              v
                  composed image と focus 値を保存
```

顔検出結果のイメージ:

```ts
{
  imageWidth: 2448,
  imageHeight: 3264,
  faces: [
    {
      bounds: { x: 260, y: 420, width: 620, height: 700 }
    }
  ]
}
```

変換イメージ:

```text
faceCenterX = bounds.x + bounds.width / 2
faceCenterY = bounds.y + bounds.height / 2

frontImageFocusX = faceCenterX / imageWidth
frontImageFocusY = faceCenterY / imageHeight
frontImageScale  = 顔サイズと上限から決める
```

保存値の例:

```ts
frontImageFocusX = 0.23
frontImageFocusY = 0.24
frontImageScale = 1.25
```

## 合成パターン別の見え方

### 円形

円形くり抜きでは、円の中で顔が見えやすい位置に来るように内側写真を寄せます。

```text
入力 front.jpg
+----------------------+
|  余白                 |
|    +--------+         |
|    |  顔    |         |
|    +--------+         |
|                      |
+----------------------+

円形くり抜き領域
        +----------+
        |          |
        |    顔    |
        |          |
        +----------+

成果物
+----------------------+
|                      |
|        外側写真       |
|                      |
|              +-----+ |
|              | 顔  | |
|              +-----+ |
+----------------------+
```

### 斜め

斜めカットでは、内側写真側のクリップ領域の中で顔が見えやすい位置へ寄せます。保存する focus 値は共通ですが、実際の描画は斜めカット領域に合わせて調整します。

```text
+----------------------+
| 外側写真              |
|       外側写真        |
|          ~~~~~~~~     |
|              ~~~~~~   |
|       内側写真 / 顔   |
+----------------------+
```

### 分割

左右分割では、右側の内側写真領域の中で顔が見えやすい位置へ寄せます。

```text
+-----------+----------+
| 外側写真   |          |
| 外側写真   |   顔     |
| 外側写真   |          |
+-----------+----------+
```

## 余白と拡大

顔がかなり端にある場合、完全に中央へ寄せると反対側に空白が出る可能性があります。

```text
入力 front.jpg
+----------------------+
| 顔                   |
|                      |
|                      |
+----------------------+

完全中央を無理に狙う場合
+----------------------+
|   空白?       顔      |
|                      |
+----------------------+
```

LifeCube では、不自然な空白補完や生成補完は行いません。

優先順位:

1. 余白が出ない範囲で顔中心へ寄せる。
2. 必要なら少し拡大する。
3. それでも無理な場合は、完全中央寄せより自然な切り抜きを優先する。

実装上は `cover` 表示を基本にし、描画位置をクリップ領域内で clamp します。これにより、余白を出さずに寄せられる範囲まで寄せます。

## 拡大率

- 顔が小さすぎる場合だけ `frontImageScale` を上げる。
- 過剰ズームは避ける。
- 最大拡大率の初期候補は `1.4` とする。
- 顔が十分大きい場合は、`1.0` に近い値を維持する。

パターンごとに表示領域の大きさが違うため、同じ focus 値でも最終的な見え方は異なります。円形は小さい領域、斜めは曲線クリップ領域、分割は右半分の領域に合わせて描画側で調整します。

## 保存

DB拡張は不要です。既存の項目を使います。

```text
frontImageFocusX
frontImageFocusY
frontImageScale
```

顔検出成功時:

```ts
frontImageFocusX = 検出顔中心X / 画像幅
frontImageFocusY = 検出顔中心Y / 画像高さ
frontImageScale = 顔サイズから計算した値
```

顔検出失敗時:

```ts
frontImageFocusX = 0.5
frontImageFocusY = 0.5
frontImageScale = 1.0
```

背面カメラのみ撮影では、内側写真がないため focus 項目は `null` のままにします。

## 実機確認

- 顔が中央付近にある内側写真で、従来と大きく崩れないこと。
- 顔が端にある内側写真で、顔が可能な範囲で見えやすい位置へ寄ること。
- 複数人が写っている場合、一番大きい顔が優先されること。
- 顔が写っていない場合、従来の中央寄せ合成になること。
- `円形 / 斜め / 分割` のすべてで、内側写真の顔が不自然に欠けすぎないこと。
- 過剰ズームで思い出として残したい周辺情報が失われすぎないこと。
- 顔検出失敗時にエラー表示が出ず、通常どおり保存まで進むこと。
