# プロンプト: ドキュメント再整理

`DOCS/` が探しにくくなったり、情報の重複が増えたりしたときに使うプロンプトです。

```text
あなたは LifeCube のドキュメントを再整理しています。

AGENTS.md、README.md、DOCS/ 配下のすべてのファイルを読んでください。

目的:
人間の開発者と AI エージェントの両方が、開発中に使いやすいドキュメント構成へ整理してください。

ルール:
- ドキュメント数を必要以上に増やさない。
- 明確な役割分担がない限り、新しいファイルを作らない。
- 同じ情報が複数箇所にある場合は、最も自然な1箇所に集約する。
- 現在も有効な判断は失わない。
- 未決定事項は DOCS/open-questions.md に移す。
- プロンプト雛形は、実際に貼って使いやすい形に保つ。
- Markdown と UTF-8 BOMなしを維持する。

再整理後に報告すること:
- 変更したファイル
- 移動した情報
- 削除した情報
- 残っている未決定事項
```
