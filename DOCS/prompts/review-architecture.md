# プロンプト: アーキテクチャレビュー

アーキテクチャ上のリスクを AI エージェントに確認させるときに使うプロンプトです。

```text
あなたは LifeCube のアーキテクチャをレビューしています。

以下を読んでください。
- README.md
- DOCS/README.md
- DOCS/project-overview.md
- DOCS/architecture.md
- DOCS/native-app-policy.md
- DOCS/open-questions.md

レビュー対象:
[ここに機能、領域、または提案したい判断を書く]

以下を確認してください。
- アーキテクチャ上のリスク
- モバイルプラットフォーム上のリスク
- Expo または EAS Build に関するリスク
- 状態管理、永続化、バックエンド、ナビゲーションに関する暗黙の判断
- 不足しているドキュメント
- 実装前に答えるべき質問

抽象論ではなく、このプロジェクトに関係する具体的なリスクに絞ってください。
```
